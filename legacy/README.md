# Prototipo anterior (congelado, no instalar)

`tema-independiente-1.4.0/` es el tema Sidonia construido desde cero en encargos anteriores, **sin código de Impact**.

El briefing vigente (4 de octubre de 2026) exige personalizar la copia licenciada de **Impact** en un duplicado sin publicar y prohíbe entregar un tema independiente. Por eso este prototipo:

- **no es la entrega** y **no debe subirse a Shopify** como tema;
- se conserva solo como referencia y como origen del código que se ha portado al kit de componentes (`kit/`), con los cambios que pide el briefing nuevo;
- su ZIP (`dist/sidonia-theme-1.4.0.zip`) se ha retirado del árbol de trabajo (sigue en el historial de git, commit `ad64eb7`).

Los logos, fotografías y tipografías (`theme/assets/sidonia-logo-*`, `foto-*.jpg`, `*.otf`) de este prototipo **no se reutilizan**: el briefing indica que ninguna propuesta gráfica anterior está aprobada y que los logos los aporta Sidonia. Las fuentes `.otf` tienen además la licencia web sin confirmar.

Sus herramientas siguen funcionando desde su propia carpeta (por ejemplo `node legacy/tema-independiente-1.4.0/tools/validate-theme.mjs`), pero no se mantienen.
